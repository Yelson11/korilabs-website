Bitácora de la carrera

    Cómo se juega aquí

    • Toca una carta para elegirla (se marca en amarillo). Puedes elegir varias del mismo valor.
    • Para jugar, toca dos veces la carta o arrástrala a la pila. Si elegiste varias, arrastra una y se van todas.
    • Después de jugar tienes 5 segundos para seguir con otra carta del mismo valor. Luego juega el siguiente.
    • Las cartas que no se pueden jugar se ven más apagadas. Si no tienes jugada, recoges la pila.
    • Al final, toca una carta oculta: pasa a tu mano y, si entra, la juegas.
